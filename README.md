# Романтический сайт ♡

## Как запустить локально
Просто открой `index.html` в браузере.

## Как разместить на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи в него:
   - `index.html`
   - `style.css`
   - `script.js`
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Сохрани настройки.
6. GitHub выдаст ссылку вида:
   `https://ТВОЙ-НИК.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`

Сайт уже адаптирован под телефон: используются `viewport`, `svh`, адаптивная типографика, кнопки и отступы для маленького экрана.

Для изменения текста редактируй только `index.html`.
Для изменения внешнего вида — `style.css`.
Для изменения поведения кнопок — `script.js`.
